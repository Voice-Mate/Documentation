## Set up the Voice Mate app

> [!info] Getting Started
> You'll need a Slack account to proceed.

1. **Create a Slack app**

   - Go to [Slack API](https://api.slack.com/apps) and create a new app.
   - Choose a workspace to install the app in.
   - Under _Features_, click on _Incoming Webhooks_ and enable it.

2. **Obtain the webhook URL**

   - In the _Incoming Webhooks_ section, click on _Add New Webhook to Workspace_.
   - Select the channel where you want to receive messages and click _Allow_.
   - Copy the generated Webhook URL.

3. **Add the webhook to Voice Mate**
   - Open the Voice Mate app.
   - Go to _Integrations_ and select _Slack_.
   - Paste the copied Webhook URL into the provided field and save.

Once set up, you'll start receiving Slack messages in your chosen channel.
